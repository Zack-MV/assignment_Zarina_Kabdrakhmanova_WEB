Behind the build

BUILT TO
ADAPT.

This page uses two responsive methods. Open each note to see how the layout changes from phone to tablet to laptop.

The Disciplines section is mobile-first custom CSS: 1 card at base size, 2 from 768px, and 4 from 1200px. Its heading scale and alignment also change at wider breakpoints.

The story, events and comparison areas use containers, rows and responsive columns. Bootstrap ordering keeps important text first on mobile.
